Nymrel Remote

Privacy

Effective September 9, 2026.

What Nymrel Remote does

Nymrel Remote lets you connect computers you own or are authorized to control and ask supported clients to inspect files, search code, edit files, and run or manage processes on those paired computers.

Data used to perform a remote action

When you use a remote tool, the control plane processes the selected device, tool name, tool arguments, result, authorization state, and operational metadata needed to route and complete the request. A file read can therefore contain the file content you asked to read, and a process action can contain the command, input, or output needed for that action.

Do not use Nymrel Remote to access information or systems you are not authorized to access. Avoid sending credentials or other sensitive information through a remote command unless it is necessary for the action and you understand the destination.

Encryption and logs

Remote call arguments and successful results are encrypted at rest in the Nymrel Remote durable call store. The plaintext necessarily exists transiently inside the authenticated control-plane process while routing the request and inside the paired device process while executing it.

Audit receipts store hashes and operational metadata rather than task arguments, file bodies, command bodies, or result bodies. HTTP access logs record operational request information and do not intentionally log remote tool arguments or results. Managed process output is bounded and retained in the device-agent process memory while that agent is running.

Retention

In the standard hosted configuration, terminal remote-call records containing encrypted arguments or results are pruned after 24 hours. Consumed or expired pairing records are pruned after one hour. Tamper-evident audit receipts can remain after those payload records are removed because the receipts contain hashes and operational metadata rather than the underlying task or result bodies.

Self-hosted operators can configure different retention periods. Device credentials remain on the paired device until they expire, are replaced, or the device is revoked or unpaired.

Service providers

Nymrel may use infrastructure hosting and identity providers to operate the control plane, authenticate users, terminate TLS, and store the encrypted service state. Those providers process data only as needed to provide their infrastructure or authentication functions.

Advertising

The Nymrel Remote implementation does not include advertising trackers or an advertising-data export path, and remote file or process content is not used by the service to target advertising.

Your choices

You can stop the device agent, revoke a paired device, reduce the device account's operating-system permissions, or narrow the configured allowed directories. For a privacy question or a request concerning Nymrel-hosted service data, email contact@nymrel.com and include only the information needed to identify the account or request.

Security reports

Do not put live device tokens, credentials, private file contents, or exploitable customer data in a public issue. Send security-sensitive reports to contact@nymrel.com.
