Nymrel Remote

Use terms

Effective September 9, 2026.

Authorized computers only

Use Nymrel Remote only with computers, files, accounts, networks, and services you own or are authorized to control. Do not use it to bypass access controls or act on another person's systems without authorization.

Remote actions can change real systems

Nymrel Remote can write or overwrite files, start commands, send input to running processes, and terminate processes. A command can also communicate with external services available to the paired computer. Review important actions before approving them and maintain appropriate backups or version control for important work.

Security boundary

The device agent runs with the operating-system permissions of the account that starts it. Nymrel's policy checks and allowed-directory controls are defense layers, not an operating-system sandbox. Use a separate OS account, VM, container, or other isolation boundary when the workload requires stronger separation.

Availability and recovery

Remote connectivity can be interrupted by network, host, authentication, operating-system, or third-party infrastructure failures. Nymrel Remote includes durable call state, device heartbeats, and agent restart supervision, but you should not use it as the sole control path for emergency, safety-critical, or otherwise high-risk systems.

Data and privacy

Use of the hosted service is also governed by the Nymrel Remote privacy notice, which explains the remote-action data path, encryption, and retention behavior.

Support

For product or account support, see Nymrel Remote support or email contact@nymrel.com. Do not send passwords, device tokens, private keys, or unnecessary private file contents in a support request.
