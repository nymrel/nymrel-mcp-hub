Nymrel Remote

Support

Nymrel Remote connects supported AI clients to computers you own or are authorized to control through the Nymrel Remote control plane and device agent.

Before contacting support

Confirm that the device agent is running, the device has network access to the configured Nymrel Remote server, and the target path is inside the device's configured allowed directories. For process actions, confirm that the device account has the operating-system permission required for the command.

What to include

Email contact@nymrel.com with the product name, the approximate time of the problem, the device name, and the smallest non-sensitive description of the failure. If the client shows a call status or safe error class, include it.

What not to include

Do not send passwords, private keys, OAuth tokens, device tokens, full environment files, payment-card information, or unnecessary private file contents. Do not post exploitable security details or customer data in a public issue.

Security issues

For a suspected authentication, tenant-isolation, cryptographic, or remote-execution vulnerability, email contact@nymrel.com with enough information to reproduce the issue safely and omit live credentials.

Read the privacy notice and use terms for the hosted service.
